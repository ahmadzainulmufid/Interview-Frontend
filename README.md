# 🎙️ InterviewMate

InterviewMate adalah aplikasi antarmuka pengguna untuk sistem simulasi wawancara kerja cerdas berbasis kecerdasan buatan (AI). Aplikasi ini dirancang untuk memberikan pengalaman simulasi wawancara yang interaktif, _real-time_, dan memberikan umpan balik evaluasi secara komprehensif.

Repositori ini hanya memuat kode sisi klien (_frontend_). Untuk _backend_ AI dan pemrosesan RAG (Retrieval-Augmented Generation), silakan merujuk ke repositori _backend_ https://github.com/ahmadzainulmufid/Interview-Backend.

## ✨ Fitur Utama

- **🔐 Autentikasi Pengguna:** Sistem _login_ dan registrasi yang aman.
- **⚙️ Konfigurasi Wawancara Dinamis:** Menu tarik-turun berjenjang (_Cascading Dropdown_) untuk memilih Kategori, Peran (seperti _Software Engineer_), dan Tingkatan secara dinamis.
- **💬 Sesi Wawancara Real-time:** Antarmuka percakapan interaktif antara kandidat dan agen AI (_Interviewer_), dilengkapi dengan sistem hitung mundur waktu (_countdown timer_).
- **📊 Laporan & Transkrip Analisis:** Halaman hasil (_Interview Result_) yang menampilkan nilai, transkrip lengkap, _Technical Gap_, evaluasi _Faithfulness/Relevance_, dan rekomendasi belajar.
